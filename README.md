# Описание проекта

## Реализованный функционал

### Абстрактный базовый класс `BaseProduct`
- Определяет общий интерфейс для всех продуктов
- Абстрактные методы:
  - `__init__` - инициализация продукта
  - `__str__` - строковое представление
  - `__repr__` - представление для разработчика
  - `price` (property) - работа с ценой
  - `new_product` - фабричный метод
  - `__add__` - сложение продуктов

### Класс `Product` с миксином и валидацией
- Наследует `BaseProduct` и `LogCreationMixin`
- Атрибуты:
  - `name` (str) — название товара
  - `description` (str) — описание товара
  - `_price` (float) — цена товара (включая копейки)
  - `quantity` (int) — количество товара в наличии
- Особенности:
  - Логирование создания объектов через миксин
  - Валидация: цена > 0, количество ≥ 0
- Методы:
  - `__str__` — строковое представление в формате "Название, цена руб. Остаток: X шт."
  - `__add__` — сложение товаров по общей стоимости (цена × количество)
  - `__repr__` — представление для разработчика

### Миксин `LogCreationMixin`
- Автоматически логирует создание объектов:
  - Выводит класс объекта
  - Параметры конструктора
- Реализует метод `__repr__` для всех наследников

### Классы-наследники `Product`

#### `Smartphone` (Смартфоны)
- Дополнительные атрибуты:
  - `efficiency` (float) — производительность
  - `model` (str) — модель
  - `memory` (int) — объем памяти (ГБ)
  - `color` (str) — цвет
- Особенности:
  - Можно складывать только с другими `Smartphone`
  - Автоматическое логирование создания

#### `LawnGrass` (Газонная трава)
- Дополнительные атрибуты:
  - `country` (str) — страна-производитель
  - `germination_period` (str) — срок прорастания
  - `color` (str) — цвет
- Особенности:
  - Можно складывать только с другими `LawnGrass`
  - Автоматическое логирование создания

### Класс `Category` с автоматическим подсчетом
- Атрибуты:
  - `name` (str) — название категории
  - `description` (str) — описание категории
  - `products` (property) — строковое представление товаров
- Атрибуты класса:
  - `category_count` (int) — общее количество категорий
  - `product_count` (int) — общее количество товаров
- Методы:
  - `add_product()` — добавляет только объекты `Product` и его наследников
  - `__str__` — строковое представление в формате "Название, количество продуктов: X шт."

- Полное покрытие тестами всех классов (>90%)
- Новые тесты:
  - Корректность работы абстрактного класса
  - Логирование создания объектов
  - Проверка `__repr__` для всех классов
- Существующие проверки:
  - Корректность создания объектов
  - Наследование и полиморфизм

  - Добавление товаров в категории
  - Валидация входных данных
  - Строковые представления
